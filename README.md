
# PFO1 - Landing de Portafolio Personal

Proyecto realizado para la materia Frontend como parte de la PFO1.

El objetivo fue desarrollar una landing de portafolio personal utilizando HTML y CSS, presentando mi perfil profesional, habilidades, intereses y una forma de contacto.

## 👩‍💻 Sobre el proyecto

La landing incluye:

* Presentación personal y profesional.
* Sección "Sobre mí".
* Habilidades relacionadas con QA y testing.
* Sección de intereses personales.
* Formulario de contacto.
* Enlace a mi perfil de GitHub.
* Diseño adaptable a computadoras, tablets y dispositivos móviles.

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3
* Google Fonts
* Flexbox
* CSS Grid
* Media Queries

## 🎨 Decisiones de diseño

Elegí un diseño simple y limpio, utilizando una paleta de colores clara con violeta como color principal.

Utilicé variables CSS para mantener consistencia en los colores y facilitar posibles modificaciones futuras.

Para la distribución de los elementos utilicé Flexbox en la navegación y en la sección principal de presentación, ya que permite organizar fácilmente los elementos en una misma dirección.

Para la sección de habilidades utilicé CSS Grid, porque permite distribuir las tarjetas en columnas de manera clara y adaptable.

También incorporé transiciones en botones, enlaces y tarjetas, además de una animación personalizada de entrada para la presentación principal.

El diseño es responsive mediante Media Queries. En pantallas pequeñas se modifica la distribución de la presentación y las tarjetas de habilidades pasan de tres columnas a una.

## ♿ Accesibilidad

Se utilizaron etiquetas HTML semánticas para organizar el contenido de la página.

La imagen de perfil incluye texto alternativo mediante el atributo `alt`, la navegación utiliza `aria-label` y los campos del formulario están asociados a sus respectivos elementos `label`.
